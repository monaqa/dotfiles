# Browser preview

Pi の `/reload` 後に使用できます。

| コマンド | 動作 |
| --- | --- |
| `/preview` | 現在の会話をブラウザで表示。初期表示は user / assistant の本文のみ |
| `/preview --all` | thinking・tool call・tool result も表示した状態で開く |
| `/preview stop` | ローカルサーバーを停止 |

- 上部のチェックボックスで thinking / tools の表示を切り替えられます。
- Markdown の見出し・表・コードブロック等に対応。ライト / ダークは OS 設定に追従します。
- 「印刷 / PDF」で現在表示中の内容を印刷できます。
- **ライブ更新**に対応しています。開いている間は約 1 秒ごとに会話を取得するので、`/preview` の再実行やページの再読み込みは不要です。
- 更新対象は確定したメッセージです。assistant の生成中の文字単位のストリーミングには対応していません。
- thinking / tools のチェック状態は更新後も維持します。末尾を見ている場合だけ新しい内容へ追従し、過去の会話を読んでいる間はスクロール位置を保ちます。
- 非表示のタブは取得を休止し、タブに戻るとすぐに更新します。接続が切れた場合も最後の内容を残して再接続を試みます。
- 現在のブランチだけを表示し、compaction 前の会話も含めます。system・custom メッセージ等は表示対象外です。
- 添付画像はプレースホルダーで表示します。Markdown 内の外部画像も読み込みません。数式・Mermaid・シンタックスハイライトは未対応です。

## ローカル表示と寿命

HTML ファイルは作成しません。ランダムな URL を持つ `127.0.0.1` の HTTP サーバーで、メモリ上の HTML を表示します。外部サービス・CDN・フォントへの通信は行いません。Markdown parser は Pi の `/export` 用同梱アセットを再利用します（Pi の将来のアセット構成変更時はパス調整が必要になる可能性があります）。

同じ Pi セッションではサーバーを再利用し、ブラウザからの要求時に現在のブランチを読み取ります。会話の追加だけでなく、ブランチの移動やセッション名の変更も表示に反映します。セッション終了・切り替え・拡張の reload 時は `session_shutdown` で停止します。ブラウザの自動起動に失敗した場合は、表示された URL を手動で開けます。

本文のみ表示は **UI 上のフィルター**であり、機密情報の削除ではありません。thinking / tools もページに含まれるため、ページ全体を保存・共有する際には注意してください。

Markdown の HTML は許可リストに従って DOM を再構築し、イベント属性・スクリプト・埋め込み等を取り除きます。リンクは HTTP(S) / mailto のみ有効にします。

## 検証

`.pi` ディレクトリで `pnpm typecheck` / `pnpm test` を実行してください。localhost の待ち受けが禁止された環境では、HTTP の統合テスト 2 件は skip されます。
